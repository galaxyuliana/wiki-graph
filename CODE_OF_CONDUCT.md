# Code of Conduct

This project follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be patient, assume good intent, and keep discussions about
code and ideas — never about people. Harassment, discrimination, and
personal attacks are not tolerated anywhere in the project's spaces.

To report a problem, open an issue or contact the maintainer via the profile
links at https://github.com/galaxyuliana. Reports are handled confidentially.
